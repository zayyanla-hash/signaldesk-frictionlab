# Combined demo — about three minutes

Start at Home. The copy distinguishes independent public research in SignalDesk from synthetic funnel examples in FrictionLab. Both tools run locally without a sign-in or paid API.

## SignalDesk — 75 seconds

1. Open SignalDesk and select Firecrawl. Show the evidence matrix: five supported questions and one unknown. Qualification describes research readiness, not buying intent.
2. Inspect Workflow need. Its source-backed analyst hypothesis does not earn fact credit. Open a fact and show the exact excerpt, publication/retrieval dates and source verification status.
3. Open Analyst brief. Show labeled hypotheses and open questions. Edit Proposed next step; the draft saves locally and any analyst review resets.
4. Preview Export brief. Point to citations, unknowns and limitations. Use Markdown or Print / Save PDF. A URL to a local account is not the portable report.

## FrictionLab — 90 seconds

1. Return to Home and open FrictionLab. Keep the connected funnel and select its largest observed loss. Show numerator, denominator, absolute loss and end-to-end conversion.
2. Import the hand-checkable eight-user cohort event fixture from `src/frictionlab/fixtures/`. Declare grain and window, validate, then replace the active dataset. Explain that only ordered, mature cohorts earn cohort-conversion claims. An independent aggregate event total supports activity ratios, not user conversion.
3. Inspect the stage evidence. Observed loss is separate from possible causes; a small cohort has wide uncertainty.
4. Draft a test. Review audience, intervention, primary metric, guardrail, decision rule and instrumentation. Scenario upside is hypothetical and does not enter the brief as a forecast.
5. Export the decision brief. It carries dataset context, definitions, the observed issue, proposed test and limitations.

Close by returning to SignalDesk. Its saved analysis survives the round trip because each app has its own validated storage namespace. These are independent work samples, with no customer or commercial outcome claimed.
